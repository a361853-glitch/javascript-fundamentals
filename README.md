# JavaScript Fundamentals

Repositorio con los ejemplos prácticos desarrollados durante las sesiones de la clase de Desarrollo Basado en Plataformas, abarcando los fundamentos del lenguaje JavaScript y sus principales paradigmas.

## Contenido del Repositorio

* **`app.js`**: Ejemplos de los fundamentos de JavaScript. Incluye declaración de variables, tipos de datos, arreglos, objetos y diferentes tipos de funciones (tradicionales, anónimas y funciones flecha).
* **`cal.js`**: Ejemplos de Programación Funcional. Contiene una calculadora que demuestra el uso de composición de funciones, callbacks, promesas y operaciones asíncronas con `async/await`.
* **`poo.js`**: Ejemplos de Programación Orientada a Objetos. Muestra la implementación de una jerarquía de animales utilizando clases, constructores, encapsulamiento (getters/setters), herencia y polimorfismo.

## Requisitos
* Node.js instalado en el sistema.
